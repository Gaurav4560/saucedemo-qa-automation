# SauceDemo QA Automation

## About
UI automation testing project for the SauceDemo e-commerce website using Selenium WebDriver.

## Tech Stack
- Java 17
- Selenium WebDriver
- TestNG
- Maven
- GitHub Actions (CI)

## Framework Design
- Page Object Model (POM)
- Reusable page classes
- Automated assertions
- Explicit waits

## Test Scenarios
- Valid login
- Invalid login
- Add product to cart
- Cart verification
- Checkout navigation
- Checkout information validation
- Remove product from cart
- Product sorting by price

## Continuous Integration
Automated tests run through GitHub Actions whenever code is pushed to the repository.
