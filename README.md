# SauceDemo QA Automation

## About
A web UI automation testing project for the SauceDemo demo e-commerce website.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)

## Test Scenarios
- Valid login
- Invalid login
- Product selection
- Add product to cart
- Cart verification
- Checkout navigation

## Website Under Test
https://www.saucedemo.com/

## Project Structure
- base - WebDriver setup and teardown
- pages - Page Object classes
- tests - Test cases
